# 🏨 Hostel Management System

A Flutter-based Hostel Management System developed to simplify and manage hostel administration through a user-friendly application. The system provides features for student registration, room management, room allocation, fee details, bookings, and reports.

## 📌 Project Overview

The Hostel Management System is designed to make hostel administration easier by organizing student information, room availability, allocation details, and fee management in one application.

## ✨ Features

- **Dashboard** – Overview of hostel management activities.
- **Student Registration** – Register and manage student details.
- **Registered Students** – View registered student information.
- **Room Management** – Manage hostel room details.
- **Room Allocation** – Allocate rooms to students.
- **Fee Details** – Manage and view hostel fee information.
- **Bookings** – Manage hostel booking details.
- **Reports** – View hostel management reports.

## 🛠️ Technologies Used

- **Frontend:** Flutter
- **Programming Language:** Dart
- **Backend / Database:** Firebase
- **Development Environment:** Visual Studio Code

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code
- Firebase account
- Android Studio or an Android device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/CatherinJesinthaJ28/Hostel-Management-System.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Hostel-Management-System
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure Firebase for your environment if required.

5. Run the application:

   ```bash
   flutter run
   ```

## 🎯 Project Objective

To develop a simple and efficient hostel management application using Flutter and Firebase that helps organize hostel administration and student-related activities.
